FOIP is a service for communication in a virtual space modeled after Future University Hakodate.
It recreates a familiar university environment online and aims to support interaction between participants.

I worked on the frontend implementation.
Using React and TypeScript, I implemented UI behavior that allows users to communicate through the virtual space.

This project gave me an opportunity to think about how the context of a real place can be translated into a web-based experience.
I focused not only on building features, but also on what users see and how they act within the interface.
